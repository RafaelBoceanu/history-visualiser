# History Visualiser

Interactive 3D visualisations of historical battles and migrations, with a scenario editor.

**Live:** https://history-visualiser.vercel.app

![CI](https://github.com/RafaelBoceanu/history-visualiser/actions/workflows/ci.yml/badge.svg)

## Stack
TypeScript, React, React Three Fiber, Zustand, Vite. Deployed on Vercel.
